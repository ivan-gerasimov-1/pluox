# 🚀 Savee

## 📝 Описание

Savee - это современное веб-приложение, построенное на микросервисной архитектуре. Проект организован как монорепозиторий, что обеспечивает удобную разработку и поддержку всех компонентов системы в едином пространстве.

## 🏗 Структура проекта

```
apps/
├── frontend/      # Веб-интерфейс
├── backend/  # Бэкенд-сервис
```

## 💻 Технический стек

### Основные технологии

- 🟢 Node.js - мощная платформа для создания масштабируемых приложений
- 📦 Workspaces - эффективное управление монорепозиторием и зависимостями

### Инструменты разработки

- 🔧 EditorConfig - поддержание единого стиля кода
- 🌳 Git - контроль версий и командная разработка
- 📝 VSCode - рекомендуемый редактор кода

## 🚀 Быстрый старт

### Предварительные требования

- Node.js (версия указана в `.nvmrc`)
- npm или yarn
- Git

### Установка и запуск

1. **Настройка Node.js**

```bash
nvm use  # Активация правильной версии Node.js
```

2. **Установка зависимостей**

```bash
npm install  # Установка всех необходимых пакетов
```

3. **Запуск приложений**

Каждое приложение в директории `apps/` содержит свои инструкции по запуску. Обратитесь к README.md в соответствующей директории для получения подробной информации.

## 👩‍💻 Разработка

### Рекомендации по разработке

- Следуйте установленным правилам кодирования
- Используйте линтеры и форматтеры кода
- Пишите понятные коммиты, следуя конвенции Conventional Commits

### Полезные команды

```bash
npm run lint     # Проверка кода
npm run format   # Форматирование кода
npm run test     # Запуск тестов
```
