# Pluox Frontend

Pluox - это современное приложение для эффективного управления личными финансами. Оно помогает пользователям отслеживать свои расходы и доходы, создавать бюджеты, анализировать финансовые привычки и достигать финансовых целей. Приложение разработано с фокусом на простоту использования, безопасность и приватность данных.

## О проекте

Pluox предоставляет пользователям удобный и быстрый интерфейс с:

- Современным минималистичным дизайном
- Оптимизированной производительностью
- Поддержкой офлайн-режима
- Адаптивным интерфейсом для всех устройств

## Технологии

### Основной стек

- **React 19.0** - производительная библиотека для создания пользовательских интерфейсов с поддержкой Concurrent Mode
- **TypeScript 5.7** - надёжность и безопасность типизации
- **Vite 6.0** - сверхбыстрый инструмент разработки с мгновенным запуском и горячей перезагрузкой

### Управление данными и состоянием

- **React Query 5.62** - продвинутое управление серверным состоянием с автоматическим кэшированием и синхронизацией
- **React Router 7.0** - декларативная маршрутизация с поддержкой параллельных маршрутов

### Стилизация и UI

- **PostCSS** - современный инструментарий для CSS с поддержкой:
  - Вложенных селекторов
  - CSS переменных
  - Автопрефиксов
- **LightningCSS** - сверхбыстрая обработка и оптимизация стилей
- **Ionicons** - качественные векторные иконки

### Разработка и тестирование

- **MSW** - мок-сервер для разработки и тестирования API
- **Rollup Plugin Visualizer** - анализ размера бандла
- **TypeScript** - строгая типизация для безопасной разработки

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start
```

## Скрипты

- `npm start` - запуск dev-сервера с горячей перезагрузкой
- `npm run build` - оптимизированная production-сборка
- `npm run build@development` - development-сборка с source maps
- `npm run preview` - локальный предпросмотр собранного приложения
- `npm run analyze` - детальный анализ размера бандла

## Структура проекта

- `/src` - исходный код приложения
  - `/components` - переиспользуемые React компоненты
  - `/pages` - компоненты страниц
  - `/hooks` - кастомные React хуки
  - `/api` - интеграция с API
  - `/utils` - вспомогательные функции
  - `/styles` - глобальные стили и темы
- `/public` - статические файлы и ассеты
- `/build` - оптимизированная production-сборка
- `vite.config.ts` - конфигурация сборки и разработки
- `tsconfig.json` - настройки TypeScript
